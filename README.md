# myHawkerSG
FED Assignment Group 4

## Environment Variables Setup
1. Create and setup a firebase app with a firestore database
2. Create a copy of ``example.env.js`` as ``env.js``
2. Replace the example in your ``env.js``

## Sample Data
To generate and write the sample data to the firestore database, head to /sampledata.html

The intended main user to test with is ``testuser``, with the same username and password.
The basic named users are stall owners, while the 'real' names are customers with orders.
